# Tutorial Files

The project files for the subagents tutorial are packaged in [tut-2-claude-subagents.zip](./tut-2-claude-subagents.zip).

This archive contains the sample calculator project used throughout the tutorial, including the `.claude/agents/calc-reviewer.md` subagent definition, the `src/` and `tests/` code, and supporting reference docs such as `CLAUDE.md`, `ARCHITECTURE.md`, `CONVENTIONS.md`, `GOTCHAS.md`, and `BUILDING.md`.

The walkthrough itself is in [../notes/SUBAGENTS_TUTORIAL.md](../notes/SUBAGENTS_TUTORIAL.md).
